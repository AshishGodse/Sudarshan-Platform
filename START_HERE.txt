🔑 IMPORTANT SETUP STEP
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

To enable live stream fetching from YouTube:

1. Go to: https://console.cloud.google.com/
2. Create a new project or use existing
3. Enable "YouTube Data API v3"
4. Create an API Key in Credentials
5. Copy the key

Then edit: .env.local
Add: NEXT_PUBLIC_YOUTUBE_API_KEY=your_copied_key_here

Without this key, the UI works but won't fetch live streams.
You can test without it - just add dummy channel IDs.
